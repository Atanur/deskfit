How it works

Three steps, none of them a chore.

DeskFit never interrupts your work. It waits until Claude is busy, offers one move, and gets out of the way.

  1. Claude gets busy

    When a task runs long, a quiet line above your prompt suggests a move that fits your body, your desk and the week so far.

  2. You do one short set

    Sets last 15 to 60 seconds. A line-art figure shows the move, a big timer counts down, and you can swap it for another.

  3. The streak does the rest

    Reach your daily goal, keep the flame going, unlock badges. Rate each set and the next ones adjust.

Every screen, one look.

A calm, monochrome pane with a single signal colour for progress. Light and dark follow your system.

The planner

It picks for your body, not at random.

64 moves, each tagged with the muscles it works, where you can do it and what gear it needs. Onboarding takes about a minute.

  • Balanced by regionNeck to calves, eight body regions, tracked over the last seven days against your goal.
  • Office or homeQuiet mode, no jumping, no gear. At home, add dumbbells, a band, a kettlebell or a bar.
  • Gentle where it should beLimits like knees or lower back are respected. A set that hurts rests that area for a week.
  • It learns from youToo easy, just right, too hard: the level shifts after a few ratings.

Install

Add it from inside Claude Code.

DeskFit is a plugin. The repository is its own marketplace, so there is nothing to download by hand.

  1. Add the marketplace.
    Run the first command in any Claude Code session.
  2. Install the plugin.
    The second command installs DeskFit for your user.
  3. Open it.
    Type /workout. A short setup asks for your age, goal and where you work out, then you are ready.
$ /plugin marketplace add atanur/deskfit
$ /plugin install deskfit@deskfit
$ /workout

To remove it later: /plugin uninstall deskfit@deskfit. Your progress is stored only on your machine.

Using it

Everything lives behind one command.

The pane opens beside your conversation. Every button has a key, so you never need the mouse.

CommandWhat it does
/workoutOpen DeskFit, or start the setup the first time.
/workout movesBrowse all moves, filter by body region and place, try one.
/workout statsLevel, streak, sets per day, work by body region, badges.
/workout boardThe leaderboard, your team and your account.
/workout settingsGoal, gear, language, look, sound and your data.
/workout focus 2hPause suggestions for a while. focus off ends it.
/workout resetErase your profile and progress from this machine.

Keys inside the pane

sStart the suggested set
nShuffle to a different move
f / cFinish the set now / cancel it
h m t l oHome, Moves, Stats, Board, Settings
EscClose the pane

Prefer to stay in flow? The line above your prompt shows your streak and offers a set only when Claude is busy. You can hide it in Settings.

Privacy and leaderboards

Your body stays on your machine.

DeskFit works fully offline. Leaderboards are opt-in, and you can use the app for years without ever joining one.

  • Nothing about you is sent until you joinDeskFit downloads the public board when it opens, a plain request that carries no data of yours. Age, weight, height, goal and limits never leave your device, even if you do join.
  • A nickname is all it takesA joined account shares a nickname, points, sets and finish times. No email, no password.
  • Private team boardsCreate a team, share the invite code with colleagues, and compete on the same scores. Rotate the code or close the team any time.
  • Delete it allOne button in Settings removes your leaderboard account. Another erases everything on your device.

Run your own server

A company can host its own board. The same API runs on Cloudflare (Workers and D1) or as a single SQLite file on any machine with Node 22.13+ or Docker. Point DeskFit at it in Settings, or set it for everyone with the backendUrl plugin option.

Scores are computed by the server from signed requests, with rate limits on sign-ups and sets.

Questions

Good to know.

Is this medical advice?

No. DeskFit suggests general, low-impact exercise. Stop if something hurts and talk to a professional if you are unsure. A set you mark as "It hurt" rests that body area for a week.

Will it interrupt me while I work?

It only offers a move when Claude has been busy for a while (20 seconds by default, adjustable) and you have not hit your goal. Focus mode pauses suggestions, and the line above the prompt can be hidden.

Does it need an account or internet?

No. Everything works offline. The only thing DeskFit does online is download the public board when it opens, and send your nickname, points and sets once you choose to join. To turn even the download off, clear the server address in Settings.

I sit in an open office. Can I be quiet?

Turn on quiet mode in Settings. It removes jumping and loud moves. Moves that need gear are used only if you say you own it.

Which languages are supported?

English and Türkçe, switchable in Settings.

Who made this, and is it from Anthropic?

DeskFit is an independent, open source project by Atanur. It is not made, endorsed or supported by Anthropic.
